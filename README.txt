PUBLISH FREE WITH GITHUB PAGES
------------------------------
1. Extract this ZIP on your computer.
2. Open your GitHub account and create a NEW public repository named:
   sanatana-jnana
3. Upload all files listed above directly into the repository root.
   IMPORTANT: index.html must be in the root, not inside another folder.
4. In the repository, open Settings > Pages.
5. Under "Build and deployment", select "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for deployment. Your website address should be:
   https://YOUR-GITHUB-USERNAME.github.io/sanatana-jnana/
8. Open the URL and test all three languages on mobile and desktop.

BEFORE APPLYING FOR ADSENSE
---------------------------
- Replace the contact email placeholder.
- Review and customize the privacy policy to match actual tools/cookies/ads.
- Publish substantial, original, useful content across your main learning sections.
- Verify Sanskrit verses, transliteration, translations and references against a reliable edition.
- Use only images, translations and media you own, have permission to use, or are licensed to reuse.
- Add a custom domain if desired; it is not mandatory for every AdSense setup.
- Apply for review in AdSense > Sites. Approval is not guaranteed.
- Do not paste AdSense code until your site is ready and you have followed Google's current setup instructions.
- Never click your own ads or ask visitors to click ads.
